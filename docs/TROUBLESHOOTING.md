## 一般的な問題

### 設定ファイルが見つからない

**症状**: `FileNotFoundError: .env file not found`

**原因**: 環境変数ファイルが作成されていない

**解決方法**:
```bash
# テンプレートファイルをコピー
python scripts/setup.py --force

# 必要な認証情報を入力
notepad .env  # Windowsの場合
```

### Python依存関係のエラー

**症状**: `ModuleNotFoundError: No module named 'xxx'`

**原因**: 必要なPythonパッケージがインストールされていない

**解決方法**:
```bash
# 依存関係をインストール
pip install -r requirements.txt

# または個別にインストール
pip install requests python-dotenv
```

### 権限エラー

**症状**: `PermissionError: [Errno 13] Permission denied`

**原因**: ファイルやディレクトリへの書き込み権限がない

**解決方法**:
```bash
# 管理者権限でコマンドプロンプトを実行
# または、ファイルの権限を確認・変更
```

## API関連の問題

### Gmail API

#### 認証エラー
**症状**: `google.auth.exceptions.RefreshError: invalid_grant`

**原因**: リフレッシュトークンが無効または期限切れ

**解決方法**:
1. 新しいリフレッシュトークンを取得
2. OAuth同意画面の設定を確認
3. APIが有効化されているか確認

#### クォータ制限
**症状**: `HttpError 429: Quota exceeded`

**原因**: APIの使用量制限に達した

**解決方法**:
1. Google Cloud Consoleでクォータを確認
2. 実行頻度を下げる
3. 必要に応じてクォータ増加を申請

### Slack API

#### トークンエラー
**症状**: `slack_sdk.errors.SlackApiError: invalid_auth`

**原因**: トークンが無効または権限不足

**解決方法**:
1. Bot TokenとUser Tokenを確認
2. 必要なスコープが付与されているか確認
3. アプリがワークスペースにインストールされているか確認

#### メッセージ取得エラー
**症状**: `channel_not_found` または `not_in_channel`

**原因**: チャンネルへのアクセス権限がない

**解決方法**:
1. Botをチャンネルに招待
2. プライベートチャンネルの場合は明示的に招待が必要
3. アーカイブされたチャンネルは取得不可

### GitHub API

#### 認証エラー
**症状**: `github.GithubException.BadCredentialsException`

**原因**: Personal Access Tokenが無効

**解決方法**:
1. トークンの有効期限を確認
2. 必要なスコープが付与されているか確認
3. 新しいトークンを生成

#### レート制限
**症状**: `github.GithubException.RateLimitExceededException`

**原因**: APIレート制限に達した

**解決方法**:
1. 1時間待機（認証済みの場合は5000リクエスト/時間）
2. 実行頻度を調整
3. GraphQL APIの使用を検討

### Google Calendar API

#### 認証エラー
**症状**: Gmail APIと同様の認証エラー

**解決方法**: Gmail APIと同じ手順で解決

#### カレンダーアクセスエラー
**症状**: `HttpError 403: Forbidden`

**原因**: カレンダーへのアクセス権限がない

**解決方法**:
1. カレンダーの共有設定を確認
2. 正しいカレンダーIDを使用しているか確認
3. プライマリカレンダーの場合は'primary'を使用

### Notion API

#### 認証エラー
**症状**: `notion_client.errors.APIResponseError: unauthorized`

**原因**: Integration Tokenが無効またはデータベースが共有されていない

**解決方法**:
1. Integration Tokenを確認
2. データベースがIntegrationと共有されているか確認
3. 権限が「Can edit」に設定されているか確認

#### データベースエラー
**症状**: `object_not_found` または `validation_error`

**原因**: データベースIDが間違っているまたはプロパティ設定が不正

**解決方法**:
1. データベースIDを再確認（32文字のID）
2. データベースのプロパティ設定を確認
3. プロパティ名とタイプが仕様と一致しているか確認

## MCP設定の問題

### MCP設定ファイルエラー

**症状**: Claude DesktopでMCPサーバーが認識されない

**原因**: mcp.jsonファイルの形式が不正または配置場所が間違っている

**解決方法**:
```bash
# 設定ファイルの妥当性を確認
python scripts/validate_config.py

# 正しい場所に配置（Windows）
copy config\mcp.json %APPDATA%\claude\mcp.json
```

### MCPサーバー接続エラー

**症状**: 個別のMCPサーバーに接続できない

**原因**: 環境変数が設定されていないまたは不正

**解決方法**:
1. `.env`ファイルの内容を確認
2. 環境変数名が正しいか確認
3. Claude Desktopを再起動

## Claude Desktop関連の問題

### アプリケーション起動エラー

**症状**: Claude Desktopが起動しない

**解決方法**:
1. アプリケーションを最新版に更新
2. 管理者権限で実行
3. ウイルス対策ソフトの除外設定を確認

### プロンプト実行エラー

**症状**: MCPサーバーを呼び出すプロンプトが動作しない

**解決方法**:
1. MCP設定が正しく読み込まれているか確認
2. 環境変数が設定されているか確認
3. より具体的なプロンプトを使用

## 認証・権限の問題

### OAuth 2.0フローエラー

**症状**: ブラウザでの認証が完了しない

**解決方法**:
1. リダイレクトURIの設定を確認
2. ブラウザのポップアップブロックを無効化
3. プライベートブラウジングモードを試す

### スコープ不足エラー

**症状**: 必要なデータにアクセスできない

**解決方法**:
1. API設定で必要なスコープが付与されているか確認
2. OAuth同意画面でスコープを追加
3. 新しいトークンを取得

## データ取得の問題

### 空のデータが返される

**症状**: APIからデータが取得できない

**原因**: フィルタリング条件が厳しすぎる

**解決方法**:
1. 日付範囲を広げる
2. フィルタリング条件を緩和
3. 手動でデータの存在を確認

### データ形式エラー

**症状**: 取得したデータの処理でエラーが発生

**原因**: APIレスポンスの形式が想定と異なる

**解決方法**:
1. APIドキュメントで最新の形式を確認
2. レスポンスデータをログ出力して確認
3. エラーハンドリングを追加

```bash
# Claude Desktopのログを確認
# Windows: %APPDATA%\claude\logs\
```

```bash
# 個別APIのテスト（開発時）
python scripts/test_individual_apis.py
```

### 4. ネットワーク接続の確認

```bash
# 基本的な接続テスト
ping api.github.com
ping slack.com
ping www.googleapis.com
```

## よくある質問

### Q: 24時間以上前のデータが取得されない

**A**: APIの制限やフィルタリング設定を確認してください。一部のAPIには取得可能な期間に制限があります。

### Q: Notionデータベースに重複データが作成される

**A**: 重複チェックロジックを確認し、一意識別子（URL等）でのフィルタリングが正しく動作しているか確認してください。

### Q: 実行が途中で止まる

**A**: ネットワーク接続、APIレート制限、認証エラーを確認してください。エラーログを確認し、該当するセクションの解決方法を試してください。

## サポート

上記の解決方法で問題が解決しない場合：

1. エラーメッセージの詳細をメモ
2. 実行環境の情報を収集
3. 設定ファイルの内容を確認（認証情報は除く）
4. 問題の再現手順を整理

これらの情報を元に、さらなる調査を行ってください。
